# Assets & Provenance

`assets/` 按正文归属分为 `papers/`、`series/`、`topics/` 和 `implementations/`。文件移动只改变路径，不修改二进制内容。

## 来源规则

- Dreamer、Genie、LingBot 与 CoCA 图片来自对应论文或原阅读材料，正文尽量给出 Figure/Table 说明。
- LingBot 的 `source/*.pdf` 是从论文源文件提取的矢量版本；个别表格是 PDF 页面裁剪，没有单独矢量文件。
- `series/lingbot-series/series-overview.*` 是系列关系总览图。
- EnerVerse-AC 的结构图和视频来自仓库阅读与官方 example 的本地运行记录。

所有附件都应由 Markdown 引用，避免形成无法判断归属的孤立素材。
