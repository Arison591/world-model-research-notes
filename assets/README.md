# Assets & Provenance

`assets/` 按内容归属分为 `papers/`、`topics/`、`comparisons/` 和 `implementations/`。文件移动只改变路径和语义化名称，不修改二进制内容。

## 来源规则

- Dreamer、Genie、LingBot 与 CoCA 的论文图片来自对应论文或原阅读材料，正文给出 Figure/Table 说明。
- LingBot 的 `source/*.pdf` 是从 arXiv 源文件提取的矢量版本；两张表格为 PDF 页面裁剪，没有单独矢量文件。
- `comparisons/lingbot-series/series-overview.*` 是为系列阅读关系制作的总览图。
- EnerVerse-AC 的结构图和视频来自仓库阅读与官方 example 的本地运行记录。
